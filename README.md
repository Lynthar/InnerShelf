# InnerShelf

Self-hosted media management for adult / JAV content — a **custom React frontend on a vanilla [Stash](https://github.com/stashapp/stash) backend**, with HTTP sidecars for metadata aggregation, subtitle generation, and (later) AI-assisted classification.

[简体中文](README.zh-CN.md)

> **Status: under development.** This repository is being bootstrapped from scratch as of 2026-04-28. Architecture, technical choices, and roadmap are documented in [`docs/development-plan.md`](docs/development-plan.md) — that document is the canonical reference until the codebase catches up.

## Looking for the Jellyfin plugin?

The InnerShelf Jellyfin plugin that previously lived in this repository has been **archived** to [Lynthar/InnerShelf-jellyfin](https://github.com/Lynthar/InnerShelf-jellyfin). The last published Jellyfin manifest is preserved on this repo's `gh-pages` branch, so existing installs continue to receive the final released version. The plugin is no longer actively developed; new feature work happens here as part of the Stash-based product.
