# InnerShelf

面向成人 / JAV 内容的自托管媒体管理应用——**基于 [Stash](https://github.com/stashapp/stash) 后端的自定义 React 前端 + 多个 HTTP 侧车**（元数据聚合、字幕生成、未来的 AI 智能分类）。

[English](README.md)

> **状态：开发中。** 本仓库于 2026-04-28 重新启动，正在从零搭建。

## 在找之前的 Jellyfin 插件？

原本位于本仓库的 InnerShelf Jellyfin 插件已**归档**至 [Lynthar/InnerShelf-jellyfin](https://github.com/Lynthar/InnerShelf-jellyfin)。本仓库 `gh-pages` 分支保留了最后一次发布的 Jellyfin manifest，已安装的用户仍可收到最终版本。插件不再主动开发，新功能均在 Stash 主产品上进行。
